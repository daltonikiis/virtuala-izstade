# Virtuālā izstāde – tīmekļa vietnes izstrādes projekts

## 1. Projekta apraksts

Projekts ir izstrādāts prakses laikā, izmantojot HTML5, CSS3 un JavaScript. Projekta mērķis ir izveidot interaktīvu un responsīvu tīmekļa vietni – virtuālu izstādi par izvēlēto tēmu.

- **Izstādes tēma:** Tehnoloģiju attīstība un inovācijas
- **Izstādes nosaukums:** Tehnoloģiju attīstība un inovācijas

Astoņi eksponāti iepazīstina ar skaitļošanas, sakaru, robotikas un mākslīgā intelekta vēsturi no 1642. līdz 1997. gadam.

## 4. Izmantotās tehnoloģijas

- **HTML5** – lapas struktūra un navigācija.
- **CSS3** – dizains, Box Model, Flexbox (navigācija, karuseļa pogas), Grid (galerija) un Media Queries.
- **JavaScript** – attēlu karuselis.
- **GitHub** – versiju kontrole un komandas darbs.

## 5. Tīmekļa vietnes funkcionalitāte

- Galvene ar navigācijas izvēlni.
- Izstādes apraksts.
- Attēlu galerija ar 8 eksponātiem.
- Karuselis ar 5 attēliem: pogas „Iepriekšējais” un „Nākamais”, automātiska pārslēgšana ik pēc 5 sekundēm, ko var apturēt un atsākt.
- Responsīvs dizains datoriem, planšetēm un telefoniem.
- Kājene ar autoriem, avotiem un attēlu licencēm.

## 6. Projekta palaišana

1. Lejupielādējiet projektu vai klonējiet repozitoriju.
2. Atveriet projekta mapi.
3. Atveriet `index.html` pārlūkprogrammā.
4. Pārbaudiet tīmekļa vietnes funkcionalitāti.

## 7. Projekta izstrādes ieguldījums

- **Ričards Maksims Reinfelds:** HTML struktūra un navigācija, CSS dizains, Flexbox/Grid, responsīvais izkārtojums un attēlu galerija.
